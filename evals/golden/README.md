# Golden set documents

`fatura/` contains invoice images sampled from the FATURA dataset and is regenerated by `evals download`.
Do not edit it by hand.

**FATURA:** M. Limam, M. Dhiaf, Y. Kessentini, *FATURA: A Multi-Layout Invoice Image Dataset for Document Analysis
and Understanding*, arXiv:2311.11856, 2023. Data: [Zenodo record 10371464](https://zenodo.org/records/10371464)
(doi:10.5281/zenodo.10371464). Licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Images are redistributed unmodified. Ground truth in `../annotations.jsonl` is derived from the FATURA annotations
as described in [docs/annotation-guidelines.md](../../docs/annotation-guidelines.md).
